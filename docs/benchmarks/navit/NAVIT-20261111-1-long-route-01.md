# NAVIT-20261111-1-long-route-01

日期：2026-11-11（Asia/Shanghai）。负责人：1（跨模块；路网接口主责 2，规划主责 3、4）。关联决策：`DEC-20261111-1-long-route-01`（本次忽略多方案对比，单方案 A）。状态：**部分完成**。本组已实测；Navit 同起终点规划耗时受阻，未测。

## 问题与方案

跨城路线（截图：武汉武昌 → 黄州商场，直线 53.5 km）报“工作区域无效或过大”。原因：标准 OSM 规划会加载两点之间的全部道路，而 `ImportedDataset::roads()` 限制区域在 0.3°×0.5° 以内，`buildNetwork` 限制 25 万节点 / 50 万边。

方案 A（仿 Navit `route_depth`）：全量路网超限或扩大后仍不连通时，改用分级路网。各层如下：

| 层 | 范围 | 道路等级 |
| --- | --- | --- |
| 1 | 起终点各 3 km | 全部道路 |
| 2 | 起终点各 15 km | motorway…tertiary（含 link） |
| 3 | 起终点外框按距离的 25%（至少 5 km）外扩 | motorway / trunk / primary（含 link）；超过 100 km 只保留 motorway / trunk |

A*、吸附、行车模式规则都不变。新增数据接口 `ImportedDataset::roadsLayered()`，分级路网的上限为 100 万节点 / 200 万引用 / 40 万条路；全量层仍限 0.3°×0.5°。

Navit 0.5.7 的 car 配置为 `route_depth="4:25%,8:40000,18:10000"`（见 `evidence/navit-route-depth.txt`），即：外框外扩 25% 内只用 order 4 的道路，40 km 内用 order 8，10 km 内用全部道路。本组把“全部道路”半径改为 3 km（武汉中心按 10 km 会超过节点上限），把 order 8 对应为 15 km 内的三级路以上；这是对 Navit 层级的近似，不是逐项复现。

## 环境与数据

Ubuntu 24.04.5 虚拟机，8 vCPU / 9.7 GiB，Release，Qt 6.4.2，GCC 13.3.0。数据为用户本机湖北缓存（SHA256 `da2b0200…0297ab`），流程与地图相同：以起点为中心加载 1 km 半径后规划。程序为临时的 `LongRoute`、`TierGap`（存档为 `.txt`，测完已删除）。

| 终点 | 直线 km | 一般 路线 km / ms | 行车 路线 km / ms |
| --- | --- | --- | --- |
| 黄州商场（截图案例） | 53.5 | 71.6 / 336 | 71.7 / 361 |
| 鄂州 | 58.0 | 67.6 / 331 | 67.7 / 351 |
| 孝感 | 56.4 | 68.2 / 326 | 68.3 / 350 |
| 咸宁 | 79.2 | 85.9 / 331 | 86.0 / 345 |
| 荆州 | 200.9 | 218.4 / 435 | 218.6 / 450 |
| 襄阳 | 264.3 | 310.2 / 571 | 310.5 / 641 |
| 宜昌 | 290.7 | 317.5 / 530 | 317.7 / 581 |
| 十堰 | 405.6 | 445.5 / 676 | 445.5 / 736 |

- 整个检查程序的峰值 RSS 为 280.7 MiB。
- 第一版分级路网沿用 25 万节点上限时，襄阳 / 宜昌 / 十堰三条加载失败（`evidence/long-route-before-limit.csv`）：264–406 km 外框内的 motorway / trunk 有 2.1–3.3 万条路，约 20–35 万个形状节点。之后分级路网改用 100 万节点上限，16/16 成功。

路线质量（`evidence/tier-gap.csv`）：武汉城区 30 对随机起终点，相距 15–30 km，全量路网（外框 +4 km）与分级路网都能加载，比较路线长度。

| 指标 | 值 |
| --- | --- |
| 分级 / 全量长度比 | 中位 1.0004，P95 1.086，最大 2.328，最小 0.976 |
| 相同（差 < 0.1%） | 17 / 30 |
| 加载 + 规划 ms（全量 / 分级） | 中位 108.5 / 261.0，P95 225.0 / 288.3 |
| 路网节点（全量 / 分级） | 中位 70,157 / 83,906 |

说明：
- 最大 2.33 倍的一例中，终点附近只能经 3 km 外的小路到达，而分级路网的中段不含小路。这就是“中段只走大路”的代价。
- 比值小于 1 的几例，是因为分级层取到了全量外框（+4 km）以外 15 km 内的干道。
- 实际使用中，分级只在全量不可用（约 45 km 以上）时启用，这些距离上没有全量结果可供对照。

## 与 Navit 的比较

| 项 | 结论 | 依据 |
| --- | --- | --- |
| 分级选路思路 | 对应（近似） | 均为“近处全部道路、远处只用高等级道路”；参数差异见上 |
